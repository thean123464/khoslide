PPT MARKET V3
=============

Day la phien ban thiet ke rieng, lay cam hung UX tu marketplace template hien dai,
khong sao chep giao dien, mau sac, logo hay tai san cua website tham khao.

CHAY TREN WINDOWS:
1. Cai Python 3.10+ (khuyen nghi Python 3.13).
2. Giai nen.
3. Double-click run.bat.
4. Mo http://127.0.0.1:5000

TRANG:
- Trang chu: /
- Kho template: /templates
- Quan tri: /admin

THANH TOAN:
- Hien tai la DEMO de test luong mua -> thanh toan -> mo khoa -> download.
- V2/V4 co the tich hop QR chuyen khoan + webhook ngan hang.

FILE:
- Dat .pptx that vao private_files.
- File khong duoc dat trong static/ de tranh public truc tiep.

Luu y bao mat:
- Doi app.secret_key truoc khi deploy.
- Trang /admin phien ban local nay chua co dang nhap admin.
